Quantitative Biology I - Student Overview

Course at a Glance

Quantitative Biology I introduces computational thinking through real biological questions. This course runs in parallel with your first-year R programming course. In programming class, you learn technical coding foundations; here, you learn how those tools are used to understand living systems.

Across the semester, you will work with models and datasets from:

  • Ecology and Evolution
  • Cell Biology
  • Plant and Environmental Biology
  • Bioinformatics and Microbiome Science

Learning Outcomes

By the end of this course, you should be able to:

  1. Explain how computational models represent biological processes.
  2. Run and interpret simulations in ecology, evolution, and cell biology.
  3. Distinguish deterministic predictions from stochastic outcomes.
  4. Analyze and visualize biological datasets using guided R workflows.
  5. Modify existing R code and Quarto notebooks to test biological hypotheses.
  6. Communicate biological conclusions using plots and quantitative evidence.

Content Overview

Module 1 (Weeks 1-3): Ecology - Population Dynamics

  • Lotka-Volterra predator-prey dynamics
  • Competition between species
  • Stability, equilibria, and oscillations

Module 2 (Weeks 4-7): Evolution - From Determinism to Randomness

  • Wright-Fisher model and genetic drift
  • Selection and selective sweeps
  • Establishment of beneficial mutations
  • Expected versus realized trajectories

Module 3 (Weeks 8-10): Cell Biology - Molecular Noise and Regulation

  • Gene expression dynamics
  • Regulatory network behavior
  • Stochastic expression and molecular noise
  • Variability in RNA-seq-like datasets

Module 4 (Weeks 11-14): Microbiomes - Complex Biological Systems

  • Microbiome fundamentals and abundance tables
  • Diversity and community structure
  • Environmental gradients and variation
  • Guided exploratory data analysis project
